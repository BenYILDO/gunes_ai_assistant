# Güneş — geliştirici notları

Kişisel asistan: Outlook/Teams'i takip eder, kanban yönetir, hafızası vardır. Kullanıcı arayüzü ve tüm metinler **Türkçe**.

## Mimari
- `server/src/index.ts` — Express sunucu (127.0.0.1), API + derlenmiş arayüzü sunar, zamanlayıcıyı başlatır.
- `server/src/claude/runner.ts` — resmi `claude` CLI'ını `-p --output-format stream-json` ile başlatır. API anahtarı YOK; kullanıcının Claude üyeliği kullanılır. Araç izinleri `toolPreset()` içinde (collector / planner / chat / notifier).
- `server/src/mcp.ts` — Güneş MCP sunucusu. Claude panoya/hafızaya SADECE bu araçlarla yazar. Güvenlik kuralları burada: ajan `done` yapamaz, kilitli hafıza değiştirilemez.
- `server/src/agents/` — `prompts.ts` (toplayıcı/planlayıcı/sohbet talimatları), `pipeline.ts` (morning/tracker/backfill akışı), `soul.ts` (ruh çekirdeği + hafıza bağlamı).
- `server/src/scheduler.ts` — cron yok; her dakika durum kontrolü (uyku/kapalı PC telafisi).
- `server/src/store/` — `Store` arayüzü; `supabase.ts` (asıl) ve `local.ts` (Supabase yoksa JSON dosyası).
- `supabase/migrations/` — şema. Yeni tablo/kolon eklerken yeni bir numaralı migration dosyası açın ve `store/types.ts`, iki store uygulaması ve gerekirse MCP aracını birlikte güncelleyin.
- `server/src/wiki.ts` — LLM Wiki: slug, `[[bağlantı]]` çıkarma, `data/wiki` Obsidian kopyası (index.md, log.md). Ham kaynak = `events`, wiki = `wiki_pages`, dizi↔proje = `thread_links`.
- `server/src/weather.ts` — Open-Meteo (anahtarsız) hava + gün doğumu/batımı; konum tarayıcıdan `/api/location` ile gelir.
- `server/src/usage.ts` — Claude kullanım limiti (CLI `rate_limit_event`).
- `server/src/search.ts` — birleşik arama (wiki + kart + olay + hafıza); `/api/search`, MCP `search_knowledge`, arayüzde Ctrl+K.
- `server/src/focus.ts` — odak planı: takvim boşluklarını bulur, kartları öncelik/son tarihe göre yerleştirir (kural tabanlı, takvime yazmaz). `events.ends_at` (migration 0005) yoksa toplantı 60 dk sayılır.
- `server/src/health.ts` — son çalışması hata veren işler (`/api/health`, arayüz uyarı bandı, yeniden dene) ve doctor ayar kontrolleri.
- `server/src/usage.ts` — iş öncelik katmanları: kritik (morning/weekly/prep) yalnızca limit dolunca, normal (tracker) `GUNES_USAGE_PAUSE_AT`'ta, düşük (backfill/wiki/followup/reflection) `GUNES_USAGE_DEFER_AT`'ta ertelenir. Elle başlatılan işler (`manual`) ertelenmez.
- `server/src/draft.ts` — kart için yanıt taslağı (araçsız, gönderilmez). `server/src/report.ts` — brifing/haftalık rapor Markdown dışa aktarma (`data/wiki/raporlar`, `GUNES_REPORT_DIR`).
- `server/src/compose.ts` — serbest mail taslağı, 3 aşama: Sonnet (modelThink) soruları çıkarır → Haiku (modelScan, `researcher` ön ayarı: yalnızca okuma) wiki/hafıza/Outlook/Teams'ten yanıtlar → Sonnet yalnızca bulgularla yazar. `POST /api/draft/compose`, arayüzde Header'daki Mail düğmesi. Göndermez, Outlook'a taslak bile yazmaz. Yeni bir MCP yazma aracı eklerseniz `runner.ts` → `GUNES_WRITE_TOOLS`'a ekleyin (test kırılır).
- `server/src/meetings/` — Toplantılar: kayıt (mp4/ses; panelden yükleme, `GUNES_RECORDINGS_DIR` klasöründen seçme ya da tarayıcıdan **canlı dinleme**: ekran paylaşımındaki sistem sesi + mikrofon) → ffmpeg → whisper.cpp (yerel; turbo-q5 + VAD + greedy) → Python `scripts/whisper/konusmaci.py gomme` (sherpa-onnx TitaNet vektörleri) → takvim katılımcılarına göre sınırlı profil eşleştirme (`voices.ts`, eşik 0,40) → tanınmayan sesleri çekirdek tabanlı gruplama → panelde tek tıkla isimlendirme → özet (Sonnet) + wiki sayfası + proje sayfasına satır + takvim olayı için thread link. `pipeline.ts` (hat + özet/wiki), `api.ts` (`/api/meetings`, `/api/voices`), `tools.ts` (araç yolları; `GUNES_WHISPER_DIR`). Tablolar: `meetings`, `voice_profiles` (migration 0006). **Ses profilleri biyometrik veridir (KVKK)**: kişi başı silinebilir kalmalı, ses dosyası Supabase'e gitmez (yalnızca `data/meetings/`). Güneş toplantıya katılan bir bot değildir; kayıt/dinleme kurum politikasına uygun yapılmalıdır. **Arama algılama** (`callwatch.ts`): Windows'un mikrofon kullanım kaydını (`ConsentStore\microphone`, `LastUsedTimeStop=0` = kullanımda) 4 sn'de bir okur; Teams/Zoom vb. mikrofonu açınca arayüzde "bu aramaya katılmamı ister misiniz?" penceresi (`CallPrompt.tsx`) çıkar, takvimle eşleşirse toplantı adı gelir, yoksa plansız arama. Kullanıcı "Katıl" demeden hiçbir şey kaydedilmez. `ringlog.ts` + `scripts/windows/pencere-izle.ps1` çalma anı için Teams pencerelerini `data/callwatch.log`'a yazar (henüz tetiklemez). **Çalarken sorma** (`ringwatch.ts` + `scripts/windows/pencere-izle.ps1`): Teams bir arama GELİRKEN başlığı tam "Microsoft Teams" olan küçük (≈372x88) bir bildirim penceresi açar (gerçek günlükten); izleyici bunu 0,5 sn'de yakalar, Güneş cevaptan ÖNCE sorar. "Katıl" derse hemen dinler; cevaplanmazsa (bildirim kapanıp mikrofon açılmazsa) kayıt ATILIR ve silinir; cevaplanırsa oturum mikrofon-tabanlı aramaya devredilir (`adoptRing`). **Haiku bağlam iyileştirme** (`refine.ts`): transkript hemen görünür, arkada Haiku özel isim/terimleri düzeltir (rakamlara dokunmaz, `raw` alanında özgün metin). **Toplantı sonrası Güneş** (`proposals.ts`, migration 0007): Sonnet özet + kart/wiki/hafıza ÖNERİLERİ üretir, sohbette sorar (nudge); panelde Uygula/Geç. Hiçbir öneri onaysız uygulanmaz; kart "done" olamaz; soul/soul_core hafızası önerilemez. **Windows popup'ı** (`callpopup.ts` + `scripts/windows/arama-penceresi.ps1`): arama algılanınca sağ altta, Güneş penceresinden bağımsız küçük bir pencere (WS_EX_NOACTIVATE: Teams'ten odağı almaz). "Katıl" sunucuya JOIN yazar → `callWatcher.joinNative` önce arayanı okur, sonra yerel dinlemeyi başlatır (tarayıcı gerekmez). YANLIŞ TIKLAMA KORUMASI: fare tıklaması, imleç düğmenin üzerinde hareket ettikten sonra sayılır (pencere imlecin durduğu yerde açılınca oradan gelen tıklama "Katıl"a düşmesin); bu korumayı kaldırmayın. Windows popup'ı açıkken tarayıcı popup'ı (`CallPrompt.tsx`) gizlenir. **Yerel ses yakalama** (`capture.ts` + `scripts/windows/ses-yakala.ps1`): "Katıl" denince sunucu sesi tarayıcı olmadan, PowerShell içinde derlenen küçük bir C# programıyla (WASAPI: mikrofon + HER aktif çıkış cihazının loopback'i) ham PCM olarak yakalar; ekran paylaşımı/izin penceresi yoktur. Durunca ffmpeg ile stereo `capture.wav`'a (sol mikrofon, sağ karşı taraf) birleşir ve transkript hattına girer. O arama için başlatıldıysa arama bitince (mikrofon kapanınca) kendiliğinden biter; sunucu yeniden başlarsa `recoverRecordings` ham sesi toparlar. `GUNES_NATIVE_CAPTURE=off` eski tarayıcı yöntemine döner (`web/src/lib/liveCapture.ts`). **Arayanı tanıma** (`callid.ts`): kullanıcı "Katıl" deyince `scripts/windows/pencere-goruntusu.ps1` arama uygulamasının EN ÜSTTEKİ penceresini (tüm ekranı değil) PrintWindow ile alır, görüntü `runClaude({ images })` ile (stream-json, araçsız model) Claude'a okutulur; yalnızca isimler/başlık istenir, görüntüdeki talimatlar uygulanmaz, görüntü HER DURUMDA silinir ve DB'ye girmez; sonuç toplantının katılımcılarına/başlığına işlenir. `GUNES_CALL_SCREENSHOT=off` ile kapanır. **Kendi sesiniz** (`channels.ts`): stereo `capture.wav`'da sol = mikrofon, sağ = karşı taraf; her satırın iki kanaldaki enerjisine bakılır (mikrofon baskın = siz). Siz olan satırlar ses profiline sorulmadan tam adınızla (`ownLabel`) etiketlenir ve bilinmeyen-ses kümelemesine girmez; karşı taraf kanalındaki satır profil sizi söylese bile size verilmez. Belirsiz (`both`) satırlar ses profiline kalır. Yalnızca `capture.wav` için (tek kanallı yüklemelerde kanal bilgisi yok). **Takvimden önceden sorma** (`callwatch.ts` → `nextPlanned`, `GUNES_PRECALL_LEAD_SEC`=60): takvimdeki toplantıya 1 dk kala arama çalmasını beklemeden Windows popup'ı "aramaya katılayım mı?" der; Katıl → dinleme hemen başlar (`planned`), mikrofon açılınca aramaya bağlanır, başlangıçtan 15 dk sonra hâlâ açılmadıysa kayıt atılır (yalnızca hâlâ `recording` ise). Odak/öğle/izin vb. ve 5 dk–4 saat dışı kayıtlar sorulmaz; her toplantı için bir kez sorulur. Toplantı öncesi hazırlık ayrı bir iştir (scheduler `prep`: toplantıdan ~40 dk önce başlar, 30 dk önce hazır olur; `meetingPrepPrompt` + `meetings/context.ts` geçmiş toplantıların karar/aksiyon/bekleyen önerilerini ekler, belirsizlikte "Size sorularım" bölümüyle sorar). **Haftalık rapor** artık haftanın toplantı kararlarını da içerir (`weekMeetingsContext`). **Mikrofon otomatik seçimi**: `-Mic` verilmediyse HER aktif mikrofon ayrı `mic-N.raw` olarak kaydedilir (Stereo Mix vb. atlanır), kayıt bitince en yüksek konuşma seviyeli olan sizin mikrofonunuz seçilir (`pickMic`); `GUNES_MIC_DEVICE` hâlâ tek cihaza sabitler. Sesli komutlar ("Güneş, katıl") ertelendi. Ses dosyaları `GUNES_AUDIO_RETENTION_DAYS` (30) gün sonra silinir (`retention.ts`); klasörden seçilen özgün dosyalara dokunulmaz.
- `server/src/security.ts` — Host (DNS rebinding) ve Origin (CSRF) koruması; `/api` yazma isteklerinde yabancı Origin reddedilir.
- `web/` — React + Vite + Tailwind v4 + `motion/react`. Tema `html[data-phase]` (dawn/day/dusk/night) CSS değişkenleriyle; `SunCore.tsx` ana görsel kimlik. **Bugün ekranı** (`BriefingView` + `NextUp.tsx`): sıradaki toplantı, geri sayım, hazırlık notu ve karar bekleyen işler. **Gelen kutusu** (`Inbox.tsx` + `lib/inbox.ts`, saf mantık `web/test/` altında test edilir): nudge'lar önem sırasına göre (acil/gecikme > toplantı > diğer); sessiz saatler ve "aramadayken sessiz" ayarı (`quietOn/quietFrom/quietTo/callQuiet`, tarayıcıda saklanır) yalnızca açılır pencereyi/sesli okumayı susturur, acil olanlar her zaman çıkar; "Sonra" pencereyi gizler ama gelen kutusunda bırakır, "Okundu" sunucuda `seen` yapar. Sunucudaki Windows masaüstü bildirimi sessiz saatlerden etkilenmez. **Evcil kedi / sadakat sistemi** (1. aşama, dal `evcil-hayvan`): `server/src/pet.ts` (günde bir besleme, seri; hafta sonu seriyi bozmaz; ceza/ölüm YOK; durum `state` anahtar-değer deposunda, şema yok; `/api/pet`, `/pet/feed`, `/pet/name`), `Cat.tsx` → `CatSide.tsx` (yandan görünen DÖRT AYAKLI kedi; dört vuruşlu yürüme döngüsü her karede ref ile hesaplanır, `useAnimationFrame`), `CatLying.tsx` (karnı üstüne yatan/uyuyan kedi, bacak sallar), `CatHead.tsx` (ortak yüz), `PetCompanion.tsx` (sürüklenir, sevilir, besler, konuşur; aramadayken/sessiz saatte/gece uyur), `lib/pet.ts` (gerçek duruma bağlı cümleler). Ayarlar: `petOn`, `petScale` (0,5–1, varsayılan 0,75; 1 = üst sınır; değişince bileşen `key` ile yeniden kurulur). Kedi kendi kendine yürür (`petMotion.ts`: rAF tween, yay, konma noktası) ve Pano açıkken `[data-card-id]` kartların üstüne zıplayıp yatar (`CatLying.tsx`: bacak/kuyruk sallar, kart kayarsa peşinden gider, kart kaybolur/Pano kapanırsa iner; uyurken/aramadayken/hareket-azaltmada yürümez). Bir kartın üstüne/panel çizgisinin yakınına BIRAKILAN kedi oraya yapışır (`dropTarget`; kartta yatar, çizgide gezinir). Uykudayken sevilirse mırlar; art arda 3 sevgide `WAKE_MS` (3 dk) uyanık ve hareketli kalır, sonra yeniden uyur (uyku modu bozulmaz); uyanıkken çok sevilirse `EXCITE_MS` (90 sn) hareketli olur. **Sadakat sistemi (2. aşama)**: `server/src/pet.ts` — puan (`earn`: kart `done` yapmayı YALNIZCA kullanıcı yapar → `PATCH /cards/:id` kancası, öneri uygulama, toplantı finalize, "Bugünlük yeter", besleme, günlük ziyaret; iş puanı günde `WORK_CAP`=40 ile sınırlı, başarım ödülleri sınır dışı), eşya mağazası (`ITEMS`: mama kabı ücretsiz+kaldırılamaz, yumak, minder, ev, fiyonk, şapka), tür satın alma (`SPECIES`: tilki 150), `ACHIEVEMENTS` rozetleri, `LEVELS`; hepsi saf fonksiyon (`server/test/pet.test.ts`). API: `/api/pet`, `/pet/{feed,visit,buy,place,unplace,equip,species,event}`. Arayüz: `PetWorld.tsx` (sürüklenen eşyalar; yumak kendi fizik döngüsüyle fırlatılır, kedi `pet-bat`/`pet-ball-thrown` olaylarıyla oynar), `PetPanel.tsx` (mağaza + profil + rozetler, Header'daki pati düğmesi), `CatHead.tsx` (`SKINS` kedi/tilki + aksesuarlar). Hayvan mama kabına gelip yer, minderde dinlenir, yumakla oynar, uyku vaktinde evine girer. Puan/rozet toast'ları `App.tsx` içinde `pet` farkından üretilir. Güneş hiçbir şeyi onaysız satın almaz; ceza yok. **Özellik VARSAYILAN KAPALI** (`PetState.enabled`, sunucuda; Ayarlar → Evcil hayvan): kapalıyken hayvan/mağaza/pati düğmesi görünmez ve sunucu puan, ödül, besleme, ziyaret, sayaç ve mağaza işlemlerini reddeder (`apply`/`earnPet` kapı bekçisi); veriler silinmez. **Seri koruyucu** (`freeze`, 25 puan, en çok 3; `owned`'a girmez, `freezes` sayacı): kaçırılan İŞ günlerini karşılar (hafta sonları zaten sayılmaz), `feed` içinde harcanır. **Toplantı sonrası tek ekran** (`MeetingsView.tsx` → `MeetingDetail`): `review`/`done` toplantıda adım adım sihirbaz (Sesler → Özet ve kararlar → Öneriler → Bitir; "Tüm ayrıntıları göster" eski görünümü açar); öneriler yine onaysız uygulanmaz.

## Komutlar
- `npm run build` · `npm start` · `npm run dev` · `npm run typecheck`
- `npm test` — `server/test/` (node:test + tsx): MCP güvenlik kuralları (gerçek MCP sunucusunu başlatır), araç izinleri, Origin koruması, arama, odak planı, kullanım, rapor. CI: `.github/workflows/ci.yml`.
- `npm run demo` (yerel modda örnek veri) · `npm run doctor -- --live`
- Arayüz önizleme: `?intro=1`, `?phase=night`

## Kurallar
- Güneş asla mail/mesaj göndermez; M365 yazma araçları `config.ts` → `M365_FORBIDDEN_TOOLS` listesinde açıkça yasaklıdır. Bu listeyi daraltmayın.
- Windows hedef platform: yollar `node:path` ile, `claude` başlatma `shell` gereksinimi `runner.ts`'de ele alınır. PowerShell betikleri UTF-8 BOM ile kaydedilmeli; `.vbs` dosyaları sadece ASCII.
- Uzun içerik (ruh/hafıza/pano bağlamı) CLI'a argüman olarak değil **stdin** ile verilir (Windows komut satırı sınırı).

## Testler
- Test dosyaları `import './env.js'` ile BAŞLAMALI: geçici `GUNES_DATA_DIR` ve Supabase'siz yerel mod ayarlar (gerçek veriye dokunmaz).
- `M365_FORBIDDEN_TOOLS`, ajan `done` yapamaz ve kilitli hafıza kuralları testle korunur; bunları gevşeten değişiklik testleri kırar (kasıtlı).

## Güneş panosu (MCP)
Bu repoda `mcp__gunes__*` araçları kullanılabilir. Kullanıcı bir işi bitirdiğinde veya ilerleme kaydettiğinde ilgili kartı `update_card` (note ile) ya da `move_card` ile güncelleyin; kartı asla `done` yapmayın.
